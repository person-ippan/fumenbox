# fumenbox
庶民's 創作譜面倉庫

1. この倉庫に入れられている各譜面には譜面IDがサブタイトルに付番されています。邪魔だと思う場合は消してください。
2. 一部音源がmp3になっているものがあります。音源がmp3になっている譜面については遅延が発生する可能性がありますのでご了承ください。
3. ダウンロードした譜面は常識の範囲でプレイなどに使ってください。
4. 各譜面のデータは以下のwikiにて閲覧できます。まだ発展途上なのでご了承ください。
https://wikiwiki.jp/shomin/%E5%89%B5%E4%BD%9C%E8%AD%9C%E9%9D%A2%E4%B8%80%E8%A6%A7
5. 非庶民的創作段位は、#4以降を順次追加していきます。
6. たまに異変が発生します。引き返さずに頑張って解決してください。
7. 配布時、または動画のサムネ左上に記されている譜面IDからお求めの譜面をお探しください。
